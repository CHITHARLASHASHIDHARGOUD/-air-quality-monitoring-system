# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public GitHub Issue.

Instead, report it by opening a private GitHub Security Advisory or emailing the repository owner directly.

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

We aim to respond within 72 hours and will work to resolve confirmed issues promptly.
