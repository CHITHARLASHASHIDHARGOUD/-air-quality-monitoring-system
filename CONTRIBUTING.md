# Contributing

Thank you for your interest in contributing to the Air Quality Monitoring & Citizen Alert System!

## How to Contribute

1. **Fork** the repository on GitHub
2. **Clone** your fork locally
3. **Create a branch** for your feature or bug fix:
   ```
   git checkout -b feature/your-feature-name
   ```
4. **Make your changes** and test them locally
5. **Commit** with a clear message:
   ```
   git commit -m "Add: brief description of change"
   ```
6. **Push** to your fork and open a **Pull Request** against `main`

## Code Style

- Java: follow standard Spring Boot conventions
- Frontend: keep HTML/CSS/JS consistent with existing style
- Add comments for non-obvious logic

## Reporting Issues

Open a GitHub Issue with:
- Steps to reproduce
- Expected vs actual behavior
- Environment details (OS, Java version, browser)
